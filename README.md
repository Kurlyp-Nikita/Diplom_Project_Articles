# Проект "ArticleHub"

Проект "ArticleHub" представляет собой элегантное веб-приложение, разработанное для публикации и просмотра статей.
Этот проект призван обогатить пользовательский опыт, предоставляя возможность читать и добавлять уникальные статьи в различные категории.

## Описание

С первых шагов на сайте пользователь погружается в мир знаний и творчества.
После регистрации, каждому пользователю открывается доступ к функционалу добавления собственных статей в категории: Спорт, Наука, Искусство.
Это позволяет пользователям делиться своими идеями и знаниями с сообществом.

Интерактивность сайта расширяется с возможностью управления добавленными статьями.
Зарегистрированные пользователи могут редактировать или удалять только свои собственные статьи,
что обеспечивает контроль за контентом и сохраняет индивидуальность каждого автора.

Личный кабинет пользователя становится центром управления его контентом.
Здесь выводится информация о категории, названии и дате добавления статей, что помогает пользователям отслеживать их вклад в каждую из категорий.

## Основные функции

- Регистрация и аутентификация пользователей
- Создание, редактирование и удаление статей
- Просмотр статей по категориям
- Комментирование статей
- Лайки статей
- Поиск статей по ключевым словам
- Фильтрация статей по категориям
- Персональный профиль пользователя со статистикой

## Технологии

Этот проект разработан с использованием современных технологий:
- Django Framework 5.0+
- SQLite (для разработки)
- Python 3.11+
- HTML5 и CSS3
- JavaScript
- Font Awesome для иконок
- Whitenoise для оптимизации статических файлов

## Установка и запуск

1. Клонировать репозиторий:
```
git clone https://github.com/yourusername/ArticleHub.git
cd ArticleHub
```

2. Создать и активировать виртуальное окружение:
```
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate  # для Windows
```

3. Установить зависимости:
```
pip install -r requirements.txt
```

4. Создать файл .env в корневой директории проекта со следующим содержимым:
```
DJANGO_SECRET_KEY=your-secret-key
DJANGO_DEBUG=True
```

5. Выполнить миграции базы данных:
```
python manage.py makemigrations
python manage.py migrate
```

6. Создать суперпользователя:
```
python manage.py createsuperuser
```

7. Собрать статические файлы:
```
python manage.py collectstatic
```

8. Запустить сервер:
```
python manage.py runserver
```

9. Откройте браузер и перейдите по адресу `http://127.0.0.1:8000/`

## Для развертывания на продакшн

Для продакшн-версии рекомендуется:
1. Установить `DJANGO_DEBUG=False` в .env файле
2. Настроить более безопасную базу данных (PostgreSQL)
3. Использовать веб-сервер, такой как Nginx, с Gunicorn
